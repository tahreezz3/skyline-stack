## Gotchas for the next session
- zsh doesn't word-split `$var`; use `${=var}` when passing multiple `--set=` args to the simulator.
- A freed Godot object compares equal to `null`; record "found" in a bool before pressing a button that frees itself.
- `UI.screen()` must use `set_anchors_and_offsets_preset`, or overlays under CanvasLayers collapse to zero size.
- First `--import` on a fresh clone prints "Cannot open strings.*.translation" once; harmless.
- Untyped values from Dictionaries/Arrays need explicit types (`var x: String = ...`): inference warnings are errors.
- The tour (`-- --tour`) never writes the save and fills the city with sample towers in memory.
