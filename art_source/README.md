# art_source/

Artists' working files: Blender scenes (`.blend`), paint files (`.psd`, `.kra`), reference sheets.
Stored with Git LFS. The game never reads this folder; exported deliverables go to `assets_inbox/` with the exact
names from `HUMAN_NEEDED.md`. See `docs/COLLABORATION.md`.

| Folder | For |
|---|---|
| `blocks/` | Building storeys, shop-front ground storeys, roofs (HR-0004) |
| `env/` | Street, city buildings, background (HR-0006) |
| `props/` | Street lamps, bench, planter, hydrant, cars (HR-0006) |
| `characters/` | The cat and any future characters |
